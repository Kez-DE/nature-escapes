# Nature Escapes

Final project for the Coursera course **Introduction to CSS3** (Web Design for Everybody, University of Michigan).

Live site: https://kez-de.github.io/nature-escapes/

## Pages

- `index.html` – home page with a hero image
- `mountains.html` – six photos laid out with CSS Grid (three columns)
- `waters.html` – six photos laid out with Flexbox; every other photo styled with `:nth-child(even)`

## CSS features

- "Skip to main content" link positioned off-screen, visible only on `:focus`
- Flexbox navigation with pill-shaped links and a hover/focus transition
- Box model on every image: `border`, `padding`, `border-radius`
- `img:hover` scale + tilt + shadow transition
- One shared stylesheet: `css/style.css`
